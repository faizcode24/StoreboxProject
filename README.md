# ✈️ Wanderlust — Travel Website

A modern and responsive travel website built using **HTML, CSS, and JavaScript**. Wanderlust is designed as a travel agency landing page where users can explore popular destinations, discover travel experiences, search for trips, and submit a travel enquiry.

## 🌍 Live Demo

**Live Demo:** `https://your-demo-url.com`

## 📸 Features

- Responsive travel agency landing page
- Modern hero section with travel search
- Popular destination cards
- Destination image hover effects
- Travel experiences section
- About Wanderlust section
- Booking/enquiry modal
- Travel enquiry form
- Date validation
- Mobile responsive navigation
- Smooth scrolling
- Responsive design for desktop, tablet, and mobile
- Pure HTML, CSS, and JavaScript

## 🛠️ Technologies Used

- **HTML5** — Website structure and semantic markup
- **CSS3** — Styling, responsive layouts, animations, and grid
- **JavaScript** — Interactions, modal, navigation, form handling, and search functionality
- **Google Fonts** — DM Sans and Playfair Display
- **Unsplash** — Travel imagery
